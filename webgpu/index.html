How it works

Each chart point is a parameter vector of the model ẋ(t) = A(t)x(t) + B(t)x(t − τ(t)). One GPU thread integrates one period with p Gauss–Legendre collocation steps (s stages; the delayed state comes from the continuous extension of the stored steps), and runs m Arnoldi steps on the resulting monodromy operator. The spectral radius ρ is the largest eigenvalue modulus of the m×m Hessenberg matrix: ρ < 1 stable (blue), ρ > 1 unstable (red).

Brute force vs MDBM

  • Brute force evaluates every grid point: the colour map of log₁₀ ρ, the boundary from the grid.
  • MDBM (multi-dimensional bisection method) evaluates a small initial grid and then only the cells that contain the boundary, halving them at every iteration — the boundary at the resolution of a (initial grid × 2iterations) grid with a fraction of the evaluations. Both can be on together.

Interactive and progressive

The brute-force map ends at one ρ per screen pixel of the plot. It is computed on nested grids (every 8th, 4th, 2nd pixel, then all; only the new points each time) and redrawn after every level, so it sharpens step by step. While a slider is dragged only the first level (the start resolution) is computed; the full chart and the MDBM boundary follow when the slider stops. Start resolution and frames per second set each other from the measured speed (default 15 fps). MDBM is drawn after every refinement step; its neighbour check runs at the end. The time limit stops a chart and keeps its last complete level.

MDBM can start from the brute-force grid (initial grid: from the brute-force grid): its sign-changing cells are refined further. With an MDBM boundary the (coarser) grid boundary is not drawn.

Forced response

With a forcing f = [f₁; f₂; …] in the model (e.g. the cutting force with the nominal chip thickness), the option periodic orbit also computes the T-periodic solution at every stable brute-force point: the fixed point x* = Φ x* + g of the one-period map (g: one period from a zero history under the forcing), solved by GMRES in the same Krylov machinery, then one more period along it. The stable region is coloured by the peak-to-peak amplitude of the first state (green, logarithmic scale from the 2nd to the 98th percentile), the unstable one by log₁₀ ρ as before. It adds about 10–20 % to a brute-force point (one Krylov space serves both ρ and the orbit); MDBM is not affected.

Zoom and pan

Mouse wheel zooms about the cursor, a left-button drag zooms into the drawn box, middle-button (or shift + left) drag pans, two fingers pinch and pan on a touch screen, double-click resets the axes. The chart is recomputed for the new range (the old image is shown stretched until the new one arrives), and the ranges in the model text follow. The divider between the panels can be dragged.

The model text

  • ζ = 0:0.05 @ 0.011 a parameter with a slider (range, start value); z = 2 a constant; ω = 2*pi*n/60 a helper (may use t);
  • T = … the period (no t), τ = … the delay (may use t), A = [a, b; c, d], B = […] (rows separated by ;);
  • functions: sin cos tan asin acos atan exp log sqrt abs floor sign step(x) mod(a,b) min max pow atan2, constant pi.

Accuracy

Float32 (WebGPU has no Float64): write the model in non-dimensional form (the examples do), so the entries of A and B are O(1). The validation page (link in the footer) compares the examples with the Float64 CPU solver of SOSD.jl. Too small m or p shows up as a ragged boundary — increase them.
